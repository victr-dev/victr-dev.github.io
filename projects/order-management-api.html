Restaurant Order Management API

In Progress
Python FastAPI REST Webhooks

Overview

An order API that simulates how online ordering platforms connect to a restaurant's POS and kitchen display. Built with Python, FastAPI, and SQLite, and tested in Postman.

What it will handle

  • Menu retrieval
  • Order creation and price calculations
  • Order status tracking
  • Request validation
  • Idempotency to prevent duplicate orders
  • Webhooks that fire when an order's status changes
